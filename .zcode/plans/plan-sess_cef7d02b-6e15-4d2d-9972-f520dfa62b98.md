# deepseek-v4flash 全面升级：现代 Web 控制面板

## 逐条解决你的反馈

| 你的问题                          | 方案                                                                                                                                                                                |
| --------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| UI 太简陋                         | 弃用 WinForms，改为**浏览器 Web 面板**（深色主题、卡片式、选项卡布局）                                                                                                              |
| 手动添加账号按键                  | 新增**账号管理页**：可添加/删除多个 zen API key（名称+密钥）                                                                                                                        |
| 随机匹配账号 IP 代理按键          | **每账号绑定独立出口节点 + 独立本地端口**；"随机分配"一键把所有账号随机匹配到不同节点                                                                                               |
| 代理订阅在哪里看/切换             | 新增**订阅管理页**：多订阅列表、添加/删除/启用禁用/强制更新，启用的订阅全部进入轮询池                                                                                               |
| IP 用不了会自动切换吗             | 健康检查 300 秒一轮，死节点自动从轮询剔除、恢复自动加回；**正在进行的单次请求不重试（流式），下一次请求自动换下一个节点**；面板可一键全量测速                                       |
| 出口本机 URL 和密钥，其他应用想用 | 设置页可**自定义端口 + 设置用户名/密码**（mihomo authentication）。无密码时 `http://127.0.0.1:7899`，有密码时 `http://用户:密码@127.0.0.1:端口`，http+socks5 同端口，默认仅本机可连 |

## 架构（全部在本文件夹内，零 npm 依赖）

```
deepseek-v4flash\
├── panel\
│   ├── server.js      # Node 22 内置 http 模块：状态管理、mihomo 配置生成、进程控制、REST API
│   └── panel.html     # 单文件深色 UI（内联 CSS/JS）
├── config\
│   ├── settings.json  # 端口/认证/默认模型/allowLan
│   ├── subs.json      # 订阅列表（名称/url/启用）
│   ├── accounts.json  # 账号列表（名称/key/绑定节点）
│   ├── opencode.json  # 默认配置（保留）
│   └── profiles\      # 每账号一份 opencode 配置（自动生成）
└── panel.bat          # 启动面板服务（隐藏）+ 自动打开浏览器 http://127.0.0.1:19098
```

**关键机制**：

- mihomo `config.yaml` 不再手改，由 server.js 从 subs/settings/accounts **自动生成**，改任何设置 → 重新生成 → 控制器 API 热加载
- 每账号一个 mihomo `listeners` 入站端口（7921 起，绑定到该账号的专属 select 组）；给该账号启动 opencode 时自动使用其端口+key → **一个账号一个固定出口 IP，随机分配按钮一键重洗**
- 桌面快捷方式不变（仍指向 panel.bat，打开后是浏览器面板）

## UI 选项卡

1. **总览**：代理运行状态、当前出口 IP、节点总数/存活数、启动/停止、一键自检
2. **订阅**：订阅卡片列表（节点数/启用开关/更新按钮）、添加新订阅输入框
3. **节点**：全部节点表格（名称/状态/延迟）、批量测速、查看当前轮询顺序
4. **账号**：账号卡片（名称/key 脱敏显示/绑定节点/专属端口）、添加/删除、**随机分配节点**、每账号"启动 opencode"按钮
5. **设置**：本地代理端口、用户名/密码（留空=无认证）、仅本机开关、默认模型下拉、其他应用接入说明（含可直接复制的代理 URL）
6. **日志**：所有操作实时日志
